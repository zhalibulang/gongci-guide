# 宫词 · 故宫英文导游词记忆站

辅助备考北京市初级导游资格考试（英语现场讲解）的静态学习站：以故宫中轴线为线索，图文并茂串联 11 个讲解站点，支持「整体纵览」与「知识点背诵」两种模式。

## 在线使用

浏览器直接打开 GitHub Pages 地址即可，无需安装任何依赖。

## 功能

- **整体纵览**：自绘紫禁城中轴平面图，11 个站点圆点即导航，颜色标记掌握进度；站点详情含实景照片、中英对照讲解词、关键数字与口试问答题。
- **知识点背诵**：三档遮罩（看全文 / 遮关键词 / 全遮背诵）、逐段或整站朗读（可调嗓音与语速）、录音跟读比对、掌握度标记（localStorage 持久化）。
- **iPad / 移动端适配**：平板竖屏地图与列表并排、触控目标加大、站点横滑切换。

## 内容与来源

- 讲解词依据《北京导游服务能力——北京现场导游考试教材》（旅游教育出版社）中英文部分整理，并结合公开资料校对，仅供个人备考学习使用。
- 站点实景图来自 [Wikimedia Commons](https://commons.wikimedia.org)，页面内各站点详情附原图出处链接；图片加载失败时显示样式化占位。

## 本地使用与修改

单文件应用：直接双击 `index.html`。

| 想改什么 | 改哪里 |
|---|---|
| 讲解词、关键词、问答 | 文件底部 `STOPS` 数组（`<m>词</m>` 为遮罩关键词） |
| 配色 | 顶部 `:root` 设计令牌（`--accent` 宫墙红等） |
| 地图站点位置 | 脚本内 `PIN_POS` 坐标表 |
